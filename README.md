# Hearty Farty Marty's Party

A single-file browser game. Everything lives in `index.html` — no build step, no dependencies.

**Play it:** https://denzmilk.github.io/hearty-farty-Marty-s-party/

## Running locally

Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server 8000
```

then visit http://localhost:8000
